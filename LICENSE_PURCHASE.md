# Adquirir Licencia Secure AI Plus

Para comprar una licencia de Secure AI Plus, envía un correo a:

**agdala.sv@gmail.com**

Indica en el asunto: **"Licencia Secure AI Plus"**

En el cuerpo del mensaje incluye:
- Nombre o usuario
- Método de pago preferido
- Número de licencias deseado

Una vez confirmado el pago, recibirás un código de licencia con el siguiente formato:

```
ABCDE-FGHJK-LMNPQ-RSTUV-WXYZ2-34567
```

### Activación

1. Abre Secure AI
2. Ve a **Configuración** → **Secure AI Plus**
3. Ingresa el código de licencia
4. Haz clic en **Activar Plus**
5. Reinicia la aplicación para disfrutar de todas las funcionalidades Plus

### Precio

- **Licencia de por vida (1 dispositivo):** **$3.00 USD** — Pago único en Bitcoin

### Método de pago

- Bitcoin (BTC) — Enviar el equivalente a **$3.00 USD** a la siguiente dirección:

**BTC:** 3L8f3v6BWwL7KBcb8AMZQ2bpE3ACne2EUf

Una vez enviado el pago, reenvía el comprobante a **agdala.sv@gmail.com** con el asunto **"Pago Licencia Secure AI Plus"** y recibirás tu código de activación.
